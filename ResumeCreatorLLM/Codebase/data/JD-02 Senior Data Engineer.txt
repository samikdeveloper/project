Position: Senior Data Engineer – Cloud & Real-time Pipelines
Location: New York, NY / Hybrid
Experience Level: 6+ years

About the Role

Develop and maintain real-time data streaming applications using Apache Kafka.

Collaborate with cross-functional teams to onboard new data sources and define schemas.
Manage infrastructure as code (Terraform) for cloud resources (AWS/GCP).
